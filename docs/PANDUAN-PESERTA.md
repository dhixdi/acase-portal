# 📖 Panduan Peserta — ASiQ UGM 2026

Dokumen ini berisi langkah-langkah lengkap bagi peserta dari awal login hingga pengumpulan Pitch Deck (bagi finalis).

---

## 1. 🔑 Login ke Portal

1. Buka link portal yang diberikan panitia.
2. Masukkan **Username** dan **Password** yang dikirim panitia melalui kanal resmi.
   - Contoh Username: `ACASE-011`
   - Contoh Password: `14d26f55`
3. Klik tombol **Masuk**.

> **Catatan:** Username bersifat *case-insensitive* (huruf besar/kecil tidak berpengaruh). Pastikan tidak ada spasi yang tidak sengaja ikut ter-*copy*.

---

## 2. 📋 Isi Biodata Tim

Setelah login, Anda akan diarahkan ke **Dashboard**. Ikuti langkah-langkah pengisian biodata:

### Langkah 1 — Persetujuan
- Baca ketentuan & persetujuan dengan seksama.
- Centang kotak persetujuan, lalu klik **Lanjut**.

### Langkah 2 — Identitas Tim
- Isi **Nama Kelompok** (3–60 karakter, unik).
- Pilih **Jumlah Anggota** (2 atau 3 orang).
- Klik **Lanjut**.

### Langkah 3 — Data Anggota
- Isi data lengkap setiap anggota:
  - Nama Lengkap
  - NIM
  - Institusi / Universitas
  - Program Studi
  - Jenjang (D3 / D4 / S1)
  - Angkatan
  - Email aktif
  - Nomor WhatsApp (format: `08xx` atau `+628xx`)
- Tandai satu anggota sebagai **Ketua Tim**.
- Klik **Lanjut**.

### Langkah 4 — Bukti Mahasiswa Aktif *(Opsional)*
- Unggah scan KTM atau surat keterangan aktif kuliah (PDF/JPG/PNG, maks. 2 MB).
- Langkah ini opsional. Klik **Lewati** jika tidak diperlukan.

### Langkah 5 — Konfirmasi & Kunci Biodata
- Periksa kembali seluruh data yang diisikan.
- **⚠️ PENTING:** Setelah dikonfirmasi, **biodata tidak dapat diubah lagi**.
- Klik **Konfirmasi & Simpan** jika semua data sudah benar.

---

## 3. 🏠 Dashboard

Setelah biodata tersimpan, Anda akan diarahkan ke **Dashboard**. Di sini Anda bisa melihat:

- **Jadwal tahapan lomba** (Case Release, Case Submission, Pitch Deck)
- **Status penyelesaian** tiap tahap
- Tombol navigasi ke halaman terkait

---

## 4. 📄 Unduh Soal Case (Case Release)

1. Pastikan biodata sudah terisi lengkap.
2. Tunggu hingga tanggal **Case Release** tiba.
3. Klik menu **Case Release** di navbar atau klik tombol di Dashboard.
4. Unduh file soal yang tersedia.

> Halaman ini hanya dapat diakses setelah biodata lengkap **dan** periode Case Release sudah dibuka oleh panitia.

---

## 5. 📤 Upload Solusi Case (Case Submission)

1. Klik menu **Submission** di Dashboard atau navbar.
2. Upload file solusi Anda:
   - **File Utama:** format **PDF**, maksimal **10 MB**
   - *(Jika diaktifkan)* **Lampiran:** format **ZIP**, maksimal **10 MB**
3. Klik **Upload**.
4. Anda dapat **mengganti file** selama periode submission masih terbuka.
   - Klik tombol **Ganti File** untuk menimpa file sebelumnya.
5. Setelah deadline, upload tidak dapat dilakukan lagi.

> **Tips:** Upload sesegera mungkin, jangan tunggu mendekati deadline untuk menghindari masalah koneksi.

---

## 6. 🔔 Pengumuman

1. Klik ikon **🔔** (lonceng) di pojok kanan navbar.
2. Di halaman Pengumuman, Anda bisa melihat:
   - Pengumuman umum dari panitia
   - Pengumuman khusus peserta
   - **Daftar Finalis** (jika sudah diumumkan)

> Cek halaman pengumuman secara berkala untuk update penting dari panitia.

---

## 7. 🏆 Upload Pitch Deck *(Khusus Finalis)*

Jika nama tim Anda muncul di daftar finalis pada halaman Pengumuman:

1. Klik menu **Submission** di navbar.
2. Akan muncul panel **Pitch Deck Submission** (hanya terlihat bagi finalis).
3. Upload file Pitch Deck Anda:
   - Format **PDF**, maksimal **10 MB**
4. Klik **Upload**.
5. Anda dapat mengganti file selama periode Pitch Deck masih terbuka.

---

## 8. 👤 Profil Tim

1. Klik menu **Profil Tim** di navbar.
2. Di sini Anda bisa melihat ringkasan data tim dan semua anggota yang telah diisikan.

> Biodata bersifat *read-only* setelah dikonfirmasi dan tidak bisa diubah.
